## 1. 프로젝트 개요

- **프로젝트명**: OGD Integrated View
- **한 줄 소개**: 여러 공공데이터(Open Government Data) API를 수집해 하나의 통합 데이터셋으로 저장하고, 이를 기반으로 대시보드로 보여주는 프로젝트
- **배경 / 문제의식**: 공공데이터 API가 수백 개까지 늘어날 수 있어, API 정의를 체계적으로 관리하고 데이터를 한곳에 통합해 볼 수 있어야 함

## 2. 목표 및 범위

- **핵심 목표**:
  1. 수백 개 규모로 늘어날 수 있는 API를 별도 폴더/구조로 관리
  2. 각 API에서 데이터를 수집해 통합 데이터셋으로 저장
  3. 저장된 데이터를 기반으로 대시보드/뷰 제공
